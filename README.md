# 📚 Online Book Shopping

A full-stack book management and e-commerce application with a Java backend and a vanilla JavaScript frontend. Built for performance, scalability, and a smooth user experience.

---

## 🚀 Features

- 🔍 **Search** — Real-time book search by title, author, or category
- 🗂️ **Filtering** — Filter books by genre, price range, and availability
- 🔃 **Sorting** — Sort results by price, title, or date added
- 📄 **Pagination** — Efficient data loading with paginated results
- 🛒 **Shopping Cart** — Add, remove, and manage items in cart
- 💾 **Backend Persistence** — All data is handled and stored server-side

## ⚙️ Getting Started

### Prerequisites

- Java 11 or higher
- A modern web browser
- (Optional) A local server for the frontend (e.g. Live Server, Apache Tomcat)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Huseynov-Huseyn/Online-Book-Shopping.git
cd Online-Book-Shopping
```

**2. Run the Backend**

```bash
cd Backend
# Compile and run the Java backend
javac Main.java
java Main
```

> Make sure the backend server is running before opening the frontend.

**3. Open the Frontend**

Open `Frontend/Main/index.html` in your browser, or serve it with a local development server:

```bash
# Example using Python
cd Frontend/Main
python -m http.server 3000
```

Then navigate to `http://localhost:3000` in your browser.
